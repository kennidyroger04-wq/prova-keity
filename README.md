# Prova Keity — Tapiraí 2027

Aplicativo gratuito de estudos para o Processo Seletivo PSPMT 003/2026 (ACS/ACE), com 200 questões inéditas de Português e Matemática/Raciocínio Lógico, respostas explicadas e simulados. 

**Aviso:** material independente, não oficial e não composto por questões reproduzidas do IGECS. O edital prevê 20 questões de Português e 20 de Matemática e Raciocínio Lógico; não há Conhecimentos Específicos no programa da prova.

O site funciona diretamente no navegador do celular, sem login, com progresso local. Após publicar os arquivos, ative GitHub Pages em Settings → Pages → Deploy from a branch → main → /(root) → Save.
